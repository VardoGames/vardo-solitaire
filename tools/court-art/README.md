# Court card art

The jacks, queens and kings in `*.svg` come from
[Vector Playing Cards](https://github.com/notpeter/Vector-Playing-Cards),
original artwork by [Byron Knoll](http://www.byronknoll.com/), released
into the public domain (or WTFPL where public domain is not recognised).

Files are named by rank then suit: `QH.svg` is the queen of hearts.

`tools/gen_cards.py` renders them and uses only the picture inside the
frame; the corner indexes and the number cards are drawn by the script.
